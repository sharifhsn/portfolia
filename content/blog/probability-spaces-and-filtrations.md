#### General Probability Theory

##### Infinite Probability Spaces

Let’s define an infinite probability space \(\Omega_{\infty}\). This sample space is uncountably infinite, which means that the probability of any particular outcome is zero. Therefore, in order to determine the probability of an event, we define the formula for the probability of certain simple events, then use probability measures to determine the probability of more complicated events.

\(\sigma\)-algebras form the basis of these simple events: \[Explanation of \(\sigma\)-algebras found in Lecture Notes\]

###### Lebesgue Measures

The probability of picking a number in between ⅓ and ⅔ is ⅔ - ⅓ = ⅓. This is also true for open intervals because the probability of an individual point occurring is 0.

We can apply \(\sigma\)-algebras to the Lebesgue measure by generating a \(\sigma\)-algebra from the collection of all closed intervals in our interval, like:

\([0, \frac{1}{3}], [\frac{1}{2}, 1], [\frac{1}{4}, \frac{230}{243}]\)

and so on. Open intervals can be defined as a union of a sequence of closed intervals, so these are included as well. The \(\sigma\)-algebra generated by this process is the **Borel \(\sigma\)-algebra**, specifically of the subset \([0, 1]\), which is \(\mathcal{B}[0, 1]\). The Borel \(\sigma\)-algebra is a well-defined set of events (remember, an event is a set) where the outcome is a real number. In this context, under the rules of \(\sigma\)-algebras, an event is an interval, a union of intervals, a complement of an interval, or any combination of these.

###### Coin Tosses

Let’s think about coin tosses. Through **filtration** (see notes), we can define the probability of every event that can be described as a finite number of coin tosses. We can determine the probability of every individual sequence in \(\Omega_{\infty}\) by showing that their probabilities converge to zero since they are fractions that multiply together infinitely.

We can use the rules of \(\sigma\)-algebras and probability measures to determine the probability of each of these events, like how the probability measure of the union of disjoint events (remember, events are sets) is equivalent to the summation of the probability measures of each event.

There are some events that are not easily computed unless we define them in this respect. Consider

\(\lim_{n \rightarrow \infty} \frac{H_n(\omega_1 \ldots \omega_n)}{n} = \frac{1}{2}\)

which describes all sequences of tosses where the long-run probability of choosing heads is ½. This set must be in \(\mathcal{F}_{\infty}\) so we can determine its probability measure. If we choose positive integers \(m\) and \(n\), we can define

\(A_{n,m} = \{ \omega; |\frac{H_n(\omega_1 \ldots \omega_n)}{n} - \frac{1}{2} | \leq \frac{1}{m}\}\)

where this set is in \(\mathcal{F}_n\) i.e. that step in the filtration. We can define this as a combination of sets if we recognize that for each threshold \(m\), there is an \(N\) where for all \(n\) after \(N\) i.e. for all sufficiently long sequences after a certain point, the average of the sequence meets the threshold, following the definition of a limit. By considering intersections as “all of these are true” and unions as “at least one must be true”, we can define this as

\(A = \bigcap^{\infty}_{m=1} \bigcup^{\infty}_{N=1} \bigcap^{\infty}_{n=N} A_{n,m}\)

By using the law of large numbers (large enough sequences will converge to the true value), we can see that \(\mathbb{P}(A) = 1\) for probability of ½, i.e. that the probability of an outcome belonging to this set is 1

Note here that this is not the same thing as saying that every outcome occurs in this set. We can easily imagine outcomes that do not. However, any individual event has a probability of 0 of occurring, so all those exceptional events together have a probability of 0. The way we describe this technically is that the event corresponding to the set with probability measure of 1 occurs **almost surely**.

##### Random Variables and Distributions

Let’s define a random variable in the context of all this measure theory. We’ll generalize the random variable to a function \(X\) with the property that (in probability space \((\Omega, \mathcal{F}, \mathbb{P})\)

\(\{X \in B\} = \{ \omega \in \Omega; X(\omega) \in B \}\)

where \(B\) is a Borel subset of \(\mathbb{R}\), this subset of \(\Omega\) is in \(\sigma\)-algebra \(\mathcal{F}\). Essentially, this defines \(X\) as a function mapping outcome \(\omega\) to a Borel subset i.e. an interval or combination of intervals on the real number line. This is the formal way to turn probability measures into actual numbers (see dice example from lecture notes).

We are not interested in \(X\) taking a specific value as that will typically be 0, so we will usually talk about the probability that \(X \in B\).

###### Stock Prices

Let’s consider the binomial asset pricing model where \(S_0(\omega) = 4\), \(u = 2\), and \(d = 1/2\) , which is generalized as

i.e. the stock price doubles on heads and halves on tails. Let’s think of the probability of the stock price now as the distribution of mass. \(S_0 = 4\) occurs with probability one, so this random variable has a unit of mass on 4. If we move two step forwards, \(\mathbb{P}\{S_2 = 16\} = p^2\), \(\mathbb{P}\{S_2 = 4\} = 2pq\) and \(\mathbb{P}\{S_2 = 1\} = q^2\), where \(p\) and \(q\) are the probabilities of \(u\) and \(d\), respectively. There are three lumps of mass distributed between 16, 4, and 1, each with the size of their probabilities. Now let's think of spreading that mass continuously. The distribution of a random variable is about the amount of mass in a set. This distribution measure \(\mu_X\) of random variable \(X\) is a probability measure \(P\), but it is done on \(B\) rather than subsets of \(\Omega\). In other words, it measures the probability of \(X\) being in a particular Borel subset.

Random variables have distributions, but they are not the same thing. The variable is the mapping between the outcome and the real number line i.e. a function, and the distribution is a measure of the probability that the variable is a certain value, or more generally, in a certain Borel subset. A random variable can have two different distributions and two different random variables can have the same distribution. Consider \(\mathbb{P}\) as the uniform measure of \([0, 1]\). We have two random variables \(X(\omega) = \omega\) and \(Y(\omega) = 1 - \omega\). The distribution measure of \(X\) is uniform, which means that all outcomes are equally likely. The distribution measure of \(Y\) is also uniform, despite being different from \(X\), they’re both \(b - a\).

Now instead let’s define \(\mathbb{P}\) as

\(\mathbb{P}[a, b] = \int_a^b 2 \omega d \omega = b^2 - a^2, 0 \leq a \leq b \leq 1\)

This is still a probability measure on \([0, 1]\) because \(\mathbb{P}[0, 1] = 1\). If you take a Borel subset of this interval, you can calculate its probability measure through the properties of probability measures applied to each interval that is unioned or complemented.

The distribution measure is one way to record a distribution. The other is the **cumulative distribution function** \(cdf\)

\(F(x) = \mathbb{P}\{X \leq x\}, x \in \mathbb{R}\)

The difference is that distribution measure is a direct mapping of the idea of probability measure onto the Borel subset, while the cdf is a distribution measure on the specific Borel subset \(\mu_X(-\infty, x]\). It can also be converted backwards as \(\mu_X(x, y] = F(y) - F(x)\)

Through the rules of probability measures, when the distribution measure is determined for every interval \([a, b]\) in \(\mathbb{R}\), then it is determined for every Borel subset of \(\mathbb{R}\).

We can also get more detail on the distribution in two special functions.

We can have a **density function** \(f(x)\)

\(\mu_X[a, b] = \mathbb{P}\{a \leq X \leq b\} = \int_a^b f(x)dx\)

which describes the distribution through its integral.

The **probability mass function** tells us that a random variable \(X\) takes one of the values in a particular sequence with probability 1. You could imagine, for instance, if \(X = \omega^2\), there is a probability of 1 that \(X\) is one of the values in the sequence of squared numbers. Strictly, this is defined where \(p_i = \mathbb{P}\{X = x_i\}\) and \(\Sigma_i p_i = 1\).

The sequence of numbers \(x_1, x_2, \ldots\) is a Borel subset.

Random variables can be described by a density, a probability mass function, both, or neither. This last one is very advanced.

Let’s define the **standard normal density**:

\(\varphi(x) = \frac{1}{\sqrt{2\pi}} e^{-\frac{x^2}{2}}\)

and the **cumulative normal distribution function** as

\(N(x) \ \int_{-\infty}^x \varphi(\xi) d \xi\)

This function is strictly increasing and maps \(\mathbb{R}\) to \((0, 1)\) and has a strictly increasing inverse function \(N^{-1}(y)\). Let’s consider the uniformly distributed random variable \(Y\) on probability space \((\Omega, \mathcal{F}, \mathbb{P}\), and \(X = N^{-1}(Y)\).

The distribution measure is the probability measure that \(X(\omega)\) is in the interval defined. The distribution measure of \(Y\omega\) therefore is \((N(a), N(b)\), which means that the distribution measure is \(N(b) - N(a)\) because \(Y\) is uniformly distributed, which is the same as

\(\int_a^b \varphi(x) dx\).

This distribution measure \(\mu_X\) is known as the **standard normal distribution**, and any random variable with this distribution is a **standard normal random variable**. This technique of generating a standard normal random variable is called the **probability integral transform** and it is essential to Monte Carlo simulation.

A simpler way to get a standard normal random variable is to take this integral from arbitrary \(a\) and \(b\) as a probability measure for the random variable \(X(\omega) = \omega\). This method works for any distribution, but it is not useful when we have multiple random variables with their own distributions and dependencies. For those cases we need a single probability space.

\(\mathbb{E}X = \sum_{\omega \in \Omega} X(\omega) \mathbb{P}(\omega)\)

The **probability space** is the combination of the sample space, function mapping, and probability measure: \((\Omega, \mathcal{F}, \mathbb{P})\)

If \(\mathbb{P}(A) = 1\), then the event \(A\) occurs almost surely. Doesn’t mean it can’t happen, but it has zero probability of occurring.

Example: If I were to pick a completely random real number between 0 and 1, the probability I would pick a rational number is 0, even though there clearly are rational numbers that exist.

A random variable is a function \(X\) that maps from the event space to all real numbers \(\mathbb{R}\). You’ve been doing this your whole life without knowing it. Roll a six-sided die. What’s the sample space? It’s not 1, 2, 3, 4, 5, 6, it’s a set of weird looking symbols that we *map onto* numbers. You could equally create a \(Y\) which says 6, 7, 8, 9, 10, 11.

The Borel subsets are every possible subdivision of the number line. It’s essentially a way to describe the real number line through set theory.

#### Expectation

Regular expectation is the probability of each outcome added together. How can you be certain that you’re exhaustive? We have to define elements in our sample space, and we use set theory to derive this:

\(\mathbb{E}[X] = \sum_{\omega \in \Omega} X(\omega) \mathbb{P}(\omega)\)

This looks like regular expectation, but it can be extended to understand the expectation of a function on a random variable as well.

Assume we have a fair coin. \(X(\omega)\) is 1 if \(\omega\) is heads, 0 if tails. \(Y(\omega)\) is 10 and -2 for the same.

What is \(\mathbb{E}(X)\)? \(\sum_{\omega \in \Omega} X(\omega) \mathbb{P}(\omega) = X(h) \mathbb{P}(h) + X(t) \mathbb{P}(t) = 1 * 0.5 + 0 * 0.5 = 0.5\)

Let’s think more advanced:

\(\mathbb{E}[e^x] = \mathbb{E}[g(x)] = \sum_{\omega \in \Omega} g(X)\)



Expected value are linear operators, so \(\mathbb{E}[\alpha X + \beta Y] = \alpha \mathbb{E}[X] + \beta \mathbb{E}[Y]\) this is very useful for operations

Jensen’s inequality mainly communicates that Variance is never negative: if \(\varphi\) is a convex real-valued function and if \(\mathbb{E}[X] < \infty\), then

\(\varphi(\mathbb{E}[X]) <= \mathbb{E}[\varphi(X)]\)

#### Change of Measure

We can shift between probability spaces and get different probability measures like so:

\(Z(\omega) = \frac{\tilde{\mathbb{P}}(\omega)}{\mathbb{P}(\omega)}\)

this is random variable which is almost surely nonnegative with \(\mathbb{E}[Z] = 1\).

new function:

\(\tilde{\mathbb{P}}(A) = \int_A Z(\omega) d \mathbb{P}(\omega)\)

so \(\tilde{\mathbb{P}}\) is a probability measure.

We could consider the same thing for \(\Omega\) as the set instead of \(A\), but the integral of \(Z\) with respect to the probability measure over the sample space is just the same thing as \(\mathbb{E}[Z]\), which is axiomatically 1.

\(v\mathbb{E}[XZ] = \int_{\Omega} X(\omega)\)

We know from the definition of \(Z\) as the ratio of probability measure that \(Z(\omega) d \mathbb{P}(\omega) = d \tilde{\mathbb{P}}\) which gives us our integral over \(\Omega\) and \(\mathbb{E}[Z]\)

#### Equivalent Measure

Equivalent probability measures only need to agree on which sets in \(\mathcal{F}\) have probability zero. Let’s say we’ve bent a coin so much that now landing on heads has a 10% chance. The event space is still heads and tails, but the probability measure is different because the probability of the heads event and the tail event are different. Yet, these are still equivalent because they agree that the only set with probability zero is \(\emptyset\).

#### Filtration

If we have random variable \(X\), the \(\sigma\)-algebra generated by \(X\) is \(\sigma(X)\), which is the collection of all subsets of \(\Omega\) where \((X \in B)\) for \(B\) Borel subset **Open question:** look up this up more formally.

\(\mathcal{F}(2) = \{\emptyset, \Omega, HH, HT, TH, TT, HH^c, HT^c, TH^c, TT^c, HH \cup HT, HH \cup TH, HH \cup TT, HT \cup TH, HT \cup TT, TH \cup TT \}\)

#### Measurability

If \(\mathcal{G}\) is also a \(\sigma\)-algebra, and every set in \(\sigma(X)\) is in \(\mathcal{G}\), then \(X\) is said to be \(\mathcal{G}\)-measurable. If we have

\(\Omega = \{a, b, c, d\}\),

and \(X(\omega)\) 2 if a, 0, if b or c, -2 if d

and \(Y(\omega)\) 13 if a or b, -2 if c or d

and \(Z(\omega)\) -2 if a or d, 3 if b or c

What is \(\sigma(Z)\)? In order to generate a \(\sigma\)-algebra from a random variable, we look at the partitions in the function and add those into the generator:

\(\sigma(Z) = \{\emptyset, \Omega, \{a, d\}, \{b, c\}\}\)

We can also more easily define these sets as \(\alpha\), \(\beta\), \(\gamma\), etc. to simplify writing down.

We can see that \(X\) is \(Z\)-measurable. But what does that actually mean?

Let’s say I know \(X = 2\). I do know the values of \(Y\) and \(Z\), because the outcome has to be \(a\).

But if \(X\) is 0, I have no idea what \(Y\) is. I do know what \(Z\) is.
