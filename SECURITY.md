# Security policy

Portfolia is a public, read-only personal website. Please report a suspected
vulnerability privately through the repository's [GitHub security page](https://github.com/sharifhsn/portfolia/security)
with enough detail to reproduce it. Do not include credentials, private
personal data, or an exploit in a public issue.

The public site has no authenticated write endpoints. Reports about content,
broken links, or ordinary bugs can use a normal GitHub issue when they do not
contain sensitive information.
