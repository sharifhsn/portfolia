# Context7 Library Reference

This file contains the Context7 library IDs for the main technologies and tools used or referenced in this project. This allows for easy retrieval of documentation in future sessions.

The value for max number of tokens for each search should be 10000.

For each library ID, get tokens for each of the topics I list. So for each top-level bullet point, there should be a get library docs call for every sub-bullet point under it, using the library ID and the topic listed there. If there are no topics listed, just get the library docs normally.
