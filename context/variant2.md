# Variant 2: Loop / interruption

Seed: `ZpR3OG_7SaT8TkrZnNcNw1jFROm5suSQ`

The seed is the design oracle: the opening Z cuts hard across the rounded p, R and O; the underscore introduces a pause; the repeated T and N create a steady scaffold; O and Q close the composition with a loop. Those patterns become a large circular portrait interrupting an otherwise precise, left-aligned page. This is a creative interpretation, not a claim that the random string contains intrinsic instructions.

## Tokens

- Paper blue `#e9eefc`: main surface.
- Electric blue `#233ced`: main ink and large spatial forms.
- Midnight `#15234a`: body copy.
- Citron `#e5f176`: quiet interactive accent.
- White `#ffffff`: portrait rim and resume surface.
- Muted blue `#536386`: secondary copy.
- Arial / Helvetica for direct, tightly spaced display type; Georgia for the introductory prose, which needs a more personal reading cadence.

The homepage uses one oversized shape and one oversized statement. Interior pages reuse the alignment and color with large unboxed rows for future content. Resume opens as a readable document with an adjacent download area. Mobile keeps the statement above a smaller portrait.

## Review before building

An initial technical-grid direction would resemble a generic developer dashboard. Replaced it with a single portrait loop and broad, editorial spacing. No fake terminal, decorative indices, fake published articles, or stock metrics. The work itself will eventually supply detail; current directory descriptions explicitly say content is planned.
