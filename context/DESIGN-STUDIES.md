# Portfolio design studies

Local checkout: `/Users/sharif/Code/portfolia`, branch `codex/five-design-studies`.
The Axum 0.8 / Askama 0.14 Rust stack is retained. No deployment or remote push was performed.

Run `rtk cargo run` from the repository, then open http://127.0.0.1:8095/designs.
`PORTFOLIA_BIND` overrides the loopback bind address. `rtk just preview` also works.
Templates compile into the binary: rebuild/restart after HTML or Markdown changes.
CSS and static assets are served from disk.

Each of five independently prompted agents received one string generated by Python's
`secrets.token_urlsafe(24)`, instructed to treat its shapes, repeats, rhythm, and contrasts
as meaningful design instructions. These are creative interpretations, not claims that
random strings objectively encode design. Agent briefs did not prescribe palettes.
Their plans and interpretations are in `variant1.md` through `variant5.md`.
Variant 6, Reading first, is a separate content-first revision documented in
`variant6.md`; it uses no random design seed.

All variants expose `/v/{1..6}`, `/v/{1..6}/blog`, `/v/{1..6}/projects`, and
`/v/{1..6}/resume`. The root opens the comparison gallery. Blog and project content
is intentionally planned; no invented publications or project results are presented.
The original resume and old templates remain in Git/the checkout for reference;
they are not served by the new preview routes.
